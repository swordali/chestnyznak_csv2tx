# 🛡️ GS1 Data Matrix İşlem Merkezi

Bu web uygulaması, hem hazır listelerinizi düzenler hem de dokümanlarınızdaki barkodları tarar.

## ✨ Öne Çıkan Güçlü Yönler
- **zxing-cpp Entegrasyonu:** GS1 DataMatrix formatındaki tüm özel karakterleri (`FNC1`, `GS`) hatasız çözer.
- **PyMuPDF Desteği:** Çok sayfalı PDF dosyalarını yüksek DPI kalitesinde işleyerek içerisindeki barkodları tek tek yakalar.
- **Esnek Sütun Dönüştürücü:** İster elinizdeki Excel'i ister sıfırdan taranan barkodları dilediğiniz sütun sayısında UTF-16 formatında TXT'ye çevirir.
